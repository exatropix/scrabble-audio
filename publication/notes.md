## Nouveautés de la version 2.4

- **Journal de démarrage** : à chaque lancement, le jeu note ses étapes dans le fichier **demarrage.txt**, juste à côté de ScrabbleAudio.exe. Si le jeu se ferme sans rien dire, envoyez-nous ce fichier : il indique où il s'est arrêté.
- **erreur.txt** est maintenant aussi enregistré à côté de ScrabbleAudio.exe, plus facile à trouver.
- Si vous annulez le choix du niveau au lancement, le jeu ne se ferme plus : Ctrl+N relance une partie, Ctrl+Q quitte.
- Recherche du dictionnaire plus sûre quand le jeu est installé dans Documents ou dans un dossier synchronisé.

Les dictionnaires n'ont pas changé : il suffit de remplacer les fichiers du jeu par ceux de **ScrabbleAudio.zip**.
